03 · Gaussian membership functions

\[\mu_A(x)=\exp\left(-\frac{(x-c)^2}{2\sigma^2}\right)\]

Fixed premise parameters for this consequent-learning demonstration: \(A_1:(c=0,\sigma=1)\), \(A_2:(c=2,\sigma=1)\).

Blue: A₁, purple: A₂. The fuzzy sets overlap around x = 1.

04 · Firing and normalization for all samples

For a single-input rule, \(w_i=\mu_{A_i}(x)\). Normalize using \(\bar w_i=w_i/(w_1+w_2)\).

05 · Construct the least-squares matrix

For each observation, the row of the design matrix is \([\bar w_1x,\ \bar w_1,\ \bar w_2x,\ \bar w_2]\).

xw̄₁xw̄₁w̄₂xw̄₂Target y
\[\mathbf y=X\theta,\qquad \theta=X^{+}\mathbf y\]

Since this four-by-four design matrix is nonsingular, the coefficients can also be obtained by solving \(X\theta=\mathbf y\). In practice use QR or SVD rather than explicitly calculating an inverse.

08 · Training versus inference

Training

Keep \(c,\sigma\) fixed → compute normalized weights → construct X → estimate \(p_1,r_1,p_2,r_2\) using least squares.

Inference

Keep all learned parameters fixed → provide a new x → evaluate the two rules → blend their predictions.

Next ANFIS step: Classical hybrid learning also updates the premise parameters \(c,\sigma\) using gradients propagated backward from prediction error.
