Forward propagation

Weighted sum

\[ z=w_1x_1+w_2x_2+b \]

Sigmoid output

\[ y=\sigma(z)=\frac{1}{1+e^{-z}} \]

Squared-error loss

\[ J=\frac{1}{2}(y_d-y)^2 \]
2

Backpropagation derivation

To update a parameter, we calculate how the loss changes with respect to that parameter. For \(w_1\), the chain rule gives:

\[ \frac{\partial J}{\partial w_1} = \frac{\partial J}{\partial e} \frac{\partial e}{\partial y} \frac{\partial y}{\partial z} \frac{\partial z}{\partial w_1} \]
Loss derivative \[ \frac{\partial J}{\partial e}=e=y_d-y \]
Error derivative \[ \frac{\partial e}{\partial y}=-1 \]
Sigmoid derivative \[ \frac{\partial y}{\partial z}=y(1-y) \]
Weighted-sum derivative \[ \frac{\partial z}{\partial w_1}=x_1 \]

Delta term

\[ \boxed{\delta=(y-y_d)y(1-y)} \]

This is the error signal propagated backward through the sigmoid neuron.

\[ \frac{\partial J}{\partial w_1}=\delta x_1, \qquad \frac{\partial J}{\partial w_2}=\delta x_2 \]
\[ \frac{\partial J}{\partial b}=\delta \]
2A

How backpropagation moves through the neuron

During the forward pass, information moves from the inputs toward the output. During backpropagation, the error signal moves in the opposite direction so that the model can determine how each weight and the bias affected the loss.

Forward direction

\[ (x_1,x_2)\rightarrow z\rightarrow y\rightarrow J \]

Backward direction

\[ J\rightarrow \delta\rightarrow \left( \frac{\partial J}{\partial w_1}, \frac{\partial J}{\partial w_2}, \frac{\partial J}{\partial b} \right) \]

What is actually being sent backward?

The inputs themselves do not move backward. What moves backward is gradient information: a numerical measure of how strongly each parameter contributed to the current loss.

\[ \delta=(y-y_d)y(1-y) \] \[ \frac{\partial J}{\partial w_1}=\delta x_1,\qquad \frac{\partial J}{\partial w_2}=\delta x_2,\qquad \frac{\partial J}{\partial b}=\delta \]
3

Gradient-descent update rule

\[ w_1^{\text{new}}=w_1^{\text{old}}-\eta\delta x_1 \] \[ w_2^{\text{new}}=w_2^{\text{old}}-\eta\delta x_2 \] \[ b^{\text{new}}=b^{\text{old}}-\eta\delta \]
For the manual calculation below, the learning rate is chosen as \(\eta=1\) only to make the arithmetic easy to follow.
4

One complete epoch by hand

Initial parameters: \[ w_1=0,\qquad w_2=0,\qquad b=0 \]

Sample 1: \((x_1,x_2)=(0,0)\), \(y_d=0\)

\[ z=(0)(0)+(0)(0)+0=0 \] \[ y=\sigma(0)=0.5 \] \[ \delta=(0.5-0)(0.5)(1-0.5)=0.125 \]
\[ w_1=0-(1)(0.125)(0)=0 \] \[ w_2=0-(1)(0.125)(0)=0 \] \[ b=0-(1)(0.125)=-0.125 \]
New \(w_1\)0
New \(w_2\)0
New \(b\)-0.125

Sample 2: \((x_1,x_2)=(0,1)\), \(y_d=1\)

\[ z=(0)(0)+(0)(1)-0.125=-0.125 \] \[ y=\sigma(-0.125)\approx0.4688 \] \[ \delta=(0.4688-1)(0.4688)(1-0.4688)\approx-0.1323 \]
\[ w_1=0-(1)(-0.1323)(0)=0 \] \[ w_2=0-(1)(-0.1323)(1)=0.1323 \] \[ b=-0.125-(1)(-0.1323)=0.0073 \]
New \(w_1\)0
New \(w_2\)0.1323
New \(b\)0.0073

Sample 3: \((x_1,x_2)=(1,0)\), \(y_d=1\)

\[ z=(0)(1)+(0.1323)(0)+0.0073=0.0073 \] \[ y=\sigma(0.0073)\approx0.5018 \] \[ \delta=(0.5018-1)(0.5018)(1-0.5018)\approx-0.1246 \]
\[ w_1=0-(1)(-0.1246)(1)=0.1246 \] \[ w_2=0.1323-(1)(-0.1246)(0)=0.1323 \] \[ b=0.0073-(1)(-0.1246)=0.1319 \]
New \(w_1\)0.1246
New \(w_2\)0.1323
New \(b\)0.1319

Sample 4: \((x_1,x_2)=(1,1)\), \(y_d=1\)

\[ z=(0.1246)(1)+(0.1323)(1)+0.1319=0.3888 \] \[ y=\sigma(0.3888)\approx0.5960 \] \[ \delta=(0.5960-1)(0.5960)(1-0.5960)\approx-0.0973 \]
\[ w_1=0.1246-(1)(-0.0973)(1)=0.2219 \] \[ w_2=0.1323-(1)(-0.0973)(1)=0.2296 \] \[ b=0.1319-(1)(-0.0973)=0.2292 \]
New \(w_1\)0.2219
New \(w_2\)0.2296
New \(b\)0.2292
